# Image-generation inputs for two-pet interactions

The only reference images for the six action sheets below are `assets/characters/feibijiubi/original.png` and `assets/characters/nuonuo/original.png` respectively. Each independent 4×4 action sheet is generated directly from the matching original with the built-in imagegen, then split into frames deterministically with `tools/process_pair_sprites.py`. `assets/pair_interactions/previews/pair-sprite-manifest.json` records the selected source images and each frame's hash. Generated action sheets or runtime frames must never be fed back into a model.

Constraints shared by all prompts: the 16 cells form a continuous timeline in row-major order; in each cell the character faces forward or turns slightly toward the interaction partner, keeping the same camera size and foot baseline, with the top of the head and both feet fully visible; a single character on a transparent or pure white background, with no second character, scenery or text. Feibi Jiubi must keep her big white hat with black and blue trim, blonde hair, blue cross hair clip, glossy purple eyes, white/black/blue uniform, black gloves and striped socks; Nuonuo must keep her grey-blue long hair, pupil-less two-tone pink and blue eyes, red-and-white outfit, red bow and both feet.

The new feeding sheet for Nuonuo was fully regenerated by the built-in imagegen **using only `assets/characters/nuonuo/original.png` as reference**; neither the old `feed_catch_nuonuo.png` nor any generated frame was used as input. The prompt emphasizes an upright head and stable feet in the first six frames, then a gradually opening mouth and puffed cheeks, strictly 4×4 row-major, transparent background, with no other character/food/text. Feibi's throwing sheet also references only her original character art; hat removal and putting the hat on reuse the existing runtime images and are not used as generation model input. These prompts define the generation intent, and the selected images and hashes define the actual production assets. If the image service is ever replaced, regenerate fully from the character originals and the action specifications above, then check each frame's head, hat, eyes, clothes, both feet, continuity between adjacent frames and the foot anchor.

The icon-kick relay uses `icon_kick_feibi.png`: the built-in imagegen was given only `assets/characters/feibijiubi/original.png`, asking for Feibi with her complete hat kicking a small object that is **not drawn** toward screen left. The 4×4 timeline is excited anticipation (0–3), crouching to wind up (4–7), extending the leg to kick and holding the contact (8–11), and bouncing back to stand proudly (12–15). Every cell fully keeps the hat, hair tips and both feet, with enough transparent margin around the small central character; no icon, second character, grid lines or text are drawn. The very first draft was discarded because the hair tips crossed cells; the final selected sheet was fully regenerated from the same original, without using the discarded draft. The runtime icon and text come from the cache of the real deleted target, not from the action sheet.
