JiuNuo Desktop Pet v1.3.3 · Behavior Control Edition · 2026-10-01

How to use
1. First exit the normal edition or any other desktop pet instance from the tray, then extract the complete package to its own folder.
2. Double-click "JiuNuoDesktopPet-BehaviorControl.exe" in the root folder; do not open the EXE inside "app" directly.
3. Right-click the pet and pick an action under "Trigger Behavior Directly"; it runs after the menu closes. "Pet Character" switches between Nuonuo and Feibi Jiubi.
4. To exit, choose "Exit Desktop Pet" from the right-click menu. The whole folder works as is; no extra runtime needs to be installed.

Separate data and notes
- This edition is not the Exclusive Feature Test launcher that demonstrates steps automatically one after another, and it does not include "test-tools".
- Both characters can manually walk, run, explore, jump, climb, sleep and be tossed; Nuonuo additionally has hunger, icon licking and slurping an icon copy, and Feibi additionally has targeted kicks, punches and charges, hat stashing, window shattering, window tearing and hat interactions.
- Feibi's targeted attacks do not require a full mischief bar first, but still need the safety conditions for real windows and character state to be met. A manual choice can attack any foreground window that is not maximized or full screen; the program never forcibly activates windows or creates test windows.
- "Stop Current Action" ends the current behavior; a window already stashed in the hat stays there until you choose "Give the Windows Back". Stashing, shattering and tearing use a window snapshot and do not harm apps or files; the icon copy never deletes the real icon or file.
- A grayed-out option means a condition is not met, such as the current character state, support surface, Quiet/Fasting Mode or an occupied hat. Windows and icons are also checked for availability when the action runs; if it cannot run, see the menu status.
- "Automatic Daily Activities (Behavior Control Edition)" is off at every start and can be turned on from the menu as needed. On first run it only copies (read-only) the normal edition's character, size, volume and mute settings, with autonomous mischief off by default; the deletion watcher is always off, and the normal edition's watched folders are never read or copied.
- Later settings and both characters' save data are always stored in %APPDATA%\SoftMochiPet\behavior-control and never overwrite the normal edition's configuration or life records.
- The normal edition and the Behavior Control Edition share single-instance protection; exit one before running the other. A new launcher never wakes up or interrupts an old instance.
- "app" contains the complete animations, voices and runtime; keep it together with the launcher in the root folder and do not mix in files from other editions.
- In this edition, window snapshots still stay only in memory, and a stashed window must be returned via right-click; safety boundaries such as switching characters, exiting and locking the screen still apply.
- The available actions are whatever the current character's menu shows; teasing still keeps its interval between repeated triggers, and mute and volume use the separate settings.
